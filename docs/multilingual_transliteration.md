# Indic LLM — Multi-Script Transliteration & Cross-Lingual Guide

## 1. Overview
The transliteration engine provides seamless cross-script conversion across 8 major Indic scripts and Romanized (Hinglish) phonetics:
- **Devanagari** (Hindi, Marathi, Sanskrit)
- **Bengali** (Bengali, Assamese)
- **Gurmukhi** (Punjabi)
- **Gujarati** (Gujarati)
- **Tamil, Telugu, Kannada, Malayalam** (Dravidian family)
